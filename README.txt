C Programming — Монгол хэлний интерактив сургалтын сайт

Файлууд:
- index.html: сайтын бүтэц
- style.css: өнгө, загвар, гар утсанд тохируулсан дизайн
- script.js: 20 хичээлийн агуулга, навигаци, дасгал, ахиц хадгалах үйлдэл

Ажиллуулах:
1. Гурван файлыг нэг хавтаст хадгал.
2. index.html файлыг Chrome дээр нээ.
3. Netlify дээр байршуулахдаа гурван файлыг нэг хавтаст байлгаж deploy хий.

Анхаарах:
- “Ажиллуулах” товч нь сургалтын зориулалттай хялбар симулятор; дурын C кодыг сервер дээр compile хийхгүй.
- Ахиц browser-ийн localStorage-д хадгалагдана. Өөр төхөөрөмж дээр автоматаар синк хийхгүй.
- Google Fonts интернет холболттой үед ачаалагдана.
